 - 『Show/hide keyboard』：「左カーソル」

## ExKeyMo_ALT_DPAD-LR_CTRL.apk
製作者垂涎のレイアウトで、Metaキーを除く主要なキーをほぼ使える配置です。入力切り替えは Ctrl + T/U/I/O/P で行なっています。
Alt、Tab、Deleteも欲しい時があるため配置しました。
Ctrlと組み合わせて使用する文字キーが左に多いため、右側にもCtrlを配置しました。
 - 『Command』：「ALT」
 - 『Clicks key』：「左カーソル」
 - 『Show/hide keyboard』：「右カーソル」
 - 『Voice』：「CTRL」
 - 『DPAD LEFT』：「TAB」
 - 『DPAD RIGHT』：「DELETE」

## ExKeyMo_ALT_DPAD-LR_META.apk
上記レイアウトの右側のCtrlをMetaキーに変更しました。
Android 16 以降の機種ではユーザー補助設定の一環として『 Metaキー + Alt + 4 』でマウスキーをONにできます。
デフォルトだと移動が遅いので、「言語とキーボード」の設定からマウスのポインター速度を変更してください（自分は一番速くしても少し遅く感じます・・・）
 - 『Command』：「ALT」
 - 『Clicks key』：「左カーソル」
 - 『Show/hide keyboard』：「右カーソル」
 - 『Voice』：「META」
 - 『DPAD LEFT』：「TAB」
 - 『DPAD RIGHT』：「DELETE」
<img width="760" height="462" alt="image" src="https://github.com/user-attachments/assets/1ce006df-feac-4710-afc5-a67a3b11c550" />

マウスキー有効時のキーマップも置いておきますが、全てを覚えるのは難しそうなので、マウス移動だけでも覚えられると少し良いかもです。ただ、この動作方法や速度だと、あまり実用的には使えないかもです。

## ExKeyMo_CTRL_DPAD-UDLR1_2ALT_META.apk
ふと、ExKeyMo の設定を見ていたら、Add Second Layout というのがあったので、そこにも入れてみました。
そうすると設定に二つ目のレイアウト（ExKeyMo Layout #2）が出てきます。
これは2種類のレイアウトを一つの APK で設定できるというものですが・・・
これを使えば擬似的に階層を増やし、いろんな設定を詰め込むことができます。
 - 『DPAD LEFT』：「TAB」
 - 『DPAD RIGHT』：「DELETE」

Layout #1
 - 『Command』：「上カーソル」
 - 『Clicks key』：「左カーソル」
 - 『Show/hide keyboard』：「右カーソル」
 - 『Voice』：「下カーソル」
 - 『DPAD UP』：「META」
 - 『DPAD DOWN』：「ALT」

Layout #2
 - 『Command』：「ALT」
 - 『Clicks key』：「左カーソル」
 - 『Show/hide keyboard』：「右カーソル」
 - 『Voice』：「META」

Gboard を設定している場合は、キーレイアウトの変更は CTRL + スペース でできます。
日本語と英語でそれぞれレイアウトを変えれば、日英の変換ボタンも不要なまま、上下左右ボタンと CTRL、ALT、META キーを最下段に設定することができます。
とここまで記載しましたが、完全に必要な人向け（製作者本人向け）なので、「そういうこともできるんだなー」というくらいで留めておきます。
