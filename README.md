# keyconfig4clicks
Clicks キーボードのキー配列（Keyconfig）やショートカットを変更・カスタマイズできるようにするための APK 配布および情報共有リポジトリです。

## 概要

このプロジェクトでは、Clicks 製物理キーボードのキーマップを変更・拡張するための非公式 APK を提供しています。公式の配列に物足りなさを感じている方や、自分好みのショートカットを割り当てたい方に向けて開発しています。

## 導入方法 (Installation)

1. **APK のダウンロード**
   - [Releases](../../releases) ページから最新の APK ファイルをダウンロードしてください。
2. **インストール**
   - Android 端末のセキュリティ設定で「不明なアプリのインストール」を許可し、ダウンロードした APK をインストールします。
3. **設定の適用**
   - アプリを起動し、画面の指示に従ってキーマップの変更を行ってください。
