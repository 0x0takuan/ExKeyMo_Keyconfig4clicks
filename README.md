# ExKeyMo_Keyconfig4clicks
Clicks 製物理キーボード（Power Keyboard/Keyboard Cases）のキー配列（Keyconfig）をExKeyMoを活用して変更・カスタマイズできるようにするための APK 配布および情報共有リポジトリです。

## 概要 (Overview)

- このプロジェクトでは、Clicks 製物理キーボードのキーマップを変更・拡張するための非公式 APK を提供しています。
- 公式の配列に物足りなさを感じている方や、自分好みの配列にしたい方に向けて開発しています。

## 導入方法 (Installation)

0. **Power Keyboard のレイアウト設定（Keyboard Cases の場合は 1. から）**
   - Android スマートフォンに Power Keyboard を接続している場合は、Android レイアウトに切り替え： Power + A を行います。
1. **Android スマートフォンの状態の設定**
   - Android スマートフォンに Clicks app を導入済みの場合は Additional Settings の各キーをデフォルト値（Tab/Alt/Gemini）に戻します。
3. **APK のダウンロード**
   - [Keyconfig](https://github.com/0x0takuan/ExKeyMo_Keyconfig4clicks/tree/main/Keyconfig)ページから自分の欲しい Keymap について最新の APK ファイルをダウンロードしてください。
4. **インストール**
   - Android 端末のセキュリティ設定で「不明なアプリのインストール」を許可し、ダウンロードした APK をインストールします。
5. **物理キーボードのキーレイアウト設定の変更**
   - 設定から、言語と入力 > 物理キーボード > Power Keyboad / Clicks Creator Keyboard を選択し、レイアウトを "ExKeyMo Layout" に変更します。
3. **再起動（別の Keymap APK をインストールした場合も）**
   - 変更したキーレイアウトを反映させるため、再起動を行ってください。
